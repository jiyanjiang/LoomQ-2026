# 对外写作流程规范（防幻觉、可复查、留痕）

> 版本：v1.0 · 配套 SOP §4

## 1. 素材来源只有两条合法通道

| 素材类型 | 通道 | 留痕要求 |
|---|---|---|
| 事实性数据（论文、数字、年份） | 查数据库 → 取详情（含 arxiv_id / 记录字段） | 记录查询 SQL / 来源记录 ID |
| 数值实验结论 | 本项目实验报告（EXPxxx） | 报告编号 + 结果片段 |

**严禁**：凭记忆编造数字 / 编造 arXiv ID / 引用数据库里不存在的文章。

## 2. 生成流程

1. 收集素材（走上述通道，逐条留痕）
2. 把素材详情发送给 DeepSeek（`deepseek-v4-pro`），按写作模板生成
3. 模板：`public/style/QJ_5.md`（默认，可用 `default_style` 切换）
4. 文稿末尾附「制作流程」：
   - 用了哪些 EXP 报告（编号）
   - 用了哪些数据库查询（SQL / 记录 ID）
   - 模板文件与版本

## 3. 校验清单

- [ ] 每个数字都能追溯到 EXP 报告或数据库记录
- [ ] 每个 arXiv ID 都在数据库中存在
- [ ] 文末附了制作流程
- [ ] 发布前用 `tools/make_share_package.py` 验证无泄漏
