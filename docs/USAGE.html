一、这是什么

LoomQ 是一个量子电路工作台，核心能力：

  • 三后端执行：同一段 OpenQASM 2.0 电路，可在 spinq（量旋）、originq（本源）、braket（AWS）三个本地模拟器上运行
  • 对齐尺子：内置 qelib1.inc 标准语义模拟器，任何电路都能算出"正确参考分布"
  • 验证闭环：生成的电路自动与参考分布比对（Hellinger ≥ 0.97），错了自动报原因
  • 电路库：内置 21 个标准电路（Bell/GHZ/QFT/Grover/W/Toffoli…），一键调用

三、日常用法

1. 跑一个标准电路（三后端）

from loomq_lib import get_qasm, run_circuit, verify_all_targets

qasm = get_qasm("a01_ghz3")                 # GHZ-3 电路
r = run_circuit(qasm, "spinq", shots=8192)
print(r["counts"], r["fidelity"], r["passed"])

v = verify_all_targets(qasm)                # 三后端批量
print(v["all_pass"])

2. 跑自定义电路

from loomq_lib import run_circuit, validate_qasm
qasm = """OPENQASM 2.0;
include "qelib1.inc";
qreg q[2]; creg c[2];
h q[0]; cx q[0], q[1];
measure q -> c;"""
ok, err = validate_qasm(qasm)
if ok:
    print(run_circuit(qasm, "originq"))

3. L2 自然语言生成（需 API key）

export LOOMQ_LLM_BASE_URL=https://api.deepseek.com

export LOOMQ_LLM_MODEL=deepseek-v4-flash

四、电路库（21 个）

别怕，这里不用懂量子力学。下面的讲解用大白话，把每个门/算法当成"玩具"来看。想亲手玩？在 Web 界面点一下电路，三后端跑出来给你看结果。

先懂两件事就够了

  • 一个量子比特就像一枚旋转中的硬币——它可以是"正面朝上"（|0⟩）、"反面朝上"（|1⟩），也可以是悬在半空没落地的叠加态。
  • 测量 = 让硬币落地。落地后只有两个结果：正面或反面，概率由叠加态决定。

4.1 十二个门

ID门通俗理解效果
g01_xX拨动开关|0⟩↔|1⟩，像反转硬币
g02_hH抛硬币确定的 |0⟩ 变悬空态，测量 50/50。起手式
g03_sS涂色（1/4 圈）给"反面"涂色。测量看不到，干涉时起作用
g04_sdgS†涂色（反向 1/4 圈）S 的反向，抵消用
g05_tT涂色（1/8 圈）比 S 更细。S+T 能涂出任意颜色
g06_tdgT†涂色（反向 1/8 圈）T 的反向，抵消用
g07_rzRZ(θ)任意角度旋钮给"反面"涂任意角度。S/T 只是它的特例
g08_ryRY(θ)任意角度翻硬币控制悬空角度：180°全翻、90°就 50/50
g09_cxCX联动开关控制位是 1 才翻转目标位。制造纠缠的核心
g10_cu1CU1(θ)受控涂色控制位是 1 才涂色。QFT 全靠它
g11_swapSWAP换座位两枚硬币交换位置。布线常用
g12_ccxCCX双开关两个控制位都是 1 才翻转。+H 能做任何量子计算

一句话记忆：X 翻面、H 抛起、S/T/RZ 涂色、RY 定角度、CX 联动、CCX 双联动、SWAP 换座、CU1 受控涂色

4.2 九个算法

ID电路通俗理解为什么有意思
a01_ghz3GHZ-3三枚硬币永远同面测一个就知道另外两个
a02_cat4猫态-4四枚硬币永远同面薛定谔的猫从 1 只变 4 只
a03_qft4QFT-4量子傅里叶变换把"频率"翻译成"位置"，很多算法的地基
a04_grover2Grover-24 个抽屉找目标经典找 4 次，量子 1 次放大答案
a05_teleport3隐形传态量子传真机不传物体，传"状态"，用纠缠当信道
a06_qft5QFT-5QFT 升到 5 比特32 态均匀，测大电路转译能力
a07_grover3Grover-38 个抽屉找目标一次迭代目标概率放大到 78%
a08_toffoli3Toffoli-3双开关门确定性 111，最简单可靠
a09_wstate3W 态恰好一盏灯亮恰好一枚正面，与 GHZ 不同家族的纠缠

算法 vs 门：门是"零件"（12 个），算法是"拼出来的机器"（9 台）。评测电路就是从这些机器里抽——不需要懂每台机器为什么这样工作，只需保证每个零件被忠实翻译。

五、常见问题

Q: 三后端结果为什么 fidelity 不是 1.0？

A: 采样噪声。8192 shots 下理论分布精确，实测有 ±1% 涨落，fidelity ≥ 0.97 即视为正确。

Q: braket 后端为什么慢？

A: braket 本地模拟器解析 OpenQASM 3，有额外转换开销。spinq/originq 直接吃 QASM 2，更快。

Q: 能上真机吗？

A: 当前版本用本地模拟器。真机需平台账号，API 已预留（backend_capabilities.json）。
