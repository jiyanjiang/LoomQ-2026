## 四、量子大富翁（用户新提案，需评估）

**规则（用户描述）**：
- 4 人（1 真人 + 3 机器 单机；或 2/3/4 真人 联机）
- 投骰子走格子，格子给量子门
- 凑出量子算法 → 按复杂度得分
- 可选：结束本轮拿分 / 继续拼更复杂算法
- 多轮比总分，或攒齐所有算法为冠军

**与教育定位的契合点**：让玩家"收集门 → 拼算法 → 得分"——潜移默化学到"门是零件、算法是机器"的量子思维。

**关键设计问题（需澄清）**：
1. 胜利法则：总分制 vs 集齐算法制？（建议集齐制更"教学完整"，总分制更"竞技"）
2. 算法出现方式："自动出"（随机给完整算法）vs "玩家拼凑"（自己从门的组合搭出）——**建议后者**，否则失去教学意义
3. 复杂度评分：按算法含门数/类型分级（如 Bell=1分、QFT=3分）
4. 量子元素：骰子是否量子化（叠加骰子）？建议保留经典骰子，量子体现在"算法"层
