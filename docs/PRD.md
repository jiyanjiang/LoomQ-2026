# LoomQ 产品需求文档（PRD）

> 版本：v2.3 · 更新：2026-08-21
> 状态：**本文件是产品的唯一权威设计源**——所有改动先改这里，再改代码。
> 原则：可交付物下降到算法+数据库层；内容全部模板化（字典/JSON），绝不 hardcode。
> 术语铁律：所有术语唯一权威源 = `web/qc_dict.py`（9 字段 schema，英文名唯一键）；文案写作规范 = 中文版"中文(英文)"、英文版"仅英文"；审稿聚焦词典。

## 一、产品定位

**方向 A：量子计算教育/科普工作台**（当前阶段）
> 架构预留方向 B：科学计算实验工作台（量子+超算+云端模型）——A 的"实验闭环"设计即 B 雏形。

一句话：**不懂量子力学，也能玩量子电路。**

- 目标用户：学生、爱好者、想入门量子的普通人（非研究生/专业研究者）
- 核心价值：拖拽搭电路 → 三后端模拟 → 可视化结果 → 通俗讲解
- 竞赛视角：直接对应"L2 交互体验"+"新手引导与视觉叙事 Bonus"人工分

## 三、核心功能清单

### 已实现（✅，截至 2026-08-19）
**L1/L2 竞赛核心**
1. **三后端执行**：spinq/originq/braket 本地模拟（loomq_lib.backends），12 门全对齐 QASM2 标准
2. **对齐尺子**：qelib1.inc 语义模拟（loomq_lib.semantics），任意电路算精确参考分布
3. **验证闭环**：Hellinger ≥0.97 判定，LLM 生成电路自动自验（三后端）
4. **电路库 22 个**：12 门 + 10 算法（含 GHZ-5 评测核心），通俗讲解（web/content.py）
5. **组件化**：MeasurePanel（测量标准件：累积式+5000次直方图，Qiskit 规范）+ Histogram（Y轴0-1概率，理论绿柱）+ QasmModule（三套合一）+ Colors（单一色板）
6. **L3 噪声模拟**：4 台机器（理想/链式/棋盘/噪声）+ 退极化+测量错误+拓扑约束（loomq_lib/noise.py）

**Web 产品**
7. **拖拽搭电路（Composer）**：门托盘 → 画布 → 实时 QASM → 一键复制 → 运行；**QASM↔画布双向同步**（文本可编辑，防抖 150ms 反向解析渲染，未知门经 GATE_SVG 渲染并 log 提示）+ **LLM 自动搭建**（聊天「自动搭建」勾选 → loadQasm 填画布 + 切视图高亮）+ **紧凑布局 v2**（列宽 36/行高 40，40 门电路画布 1746→1498 即 -14%；多比特门透明框固定 28px 不越列，修复右侧相邻列横向拖放被拦截）
8. **布洛赫球**：three.js 3D + θ/φ 滑块 + 8 门操作 + 测量标准件 + 累积收敛
9. **互动课程**：课程树 6 课，第 1 课 H 门游戏（Terry 黑球白球方案，3 关）
10. **伯特曼袜子游戏**：纠缠配对（同面/异面模式），DS 审核 8/10
11. **施温格积木游戏**：基础 8 关 + 进阶 8 题 + 测试模式 + 可胜性自检（web/selfcheck_schwinger.py，正交表矩阵/8关透挡验证），DS 审核 8/10；词条措辞统一"粒子"图像

13. **自检流程**：web/selfcheck.sh v2（5 项：术语黑名单/服务/按钮一致/视图零错）+ 每游戏独立自检脚本

## 四、技术架构

```
web/                          # Flask 应用
├── app.py                    # API 路由 + 页面（含 /api/search 词典检索、/api/chat 检索注入）
├── content.py                # 内容字典（12门/10算法讲解 + UI文案 + 课程树 + 提示词片段）
├── qc_dict.py                # ★量子计算词典（唯一权威源，9 字段 schema + REFERENCES + validate + MD/CSV）
├── templates/index.html      # 单页应用（六视图 + 右侧）
├── static/
│   ├── css/style.css         # 布局 + 主题变量
│   ├── js/colors.js          # ★单一色板（全站颜色唯一来源）
│   ├── js/components/        # ★标准组件：measure.js / histogram.js / qasm.js
│   ├── js/gates.js           # 12 门 SVG 图标（标准符号）
│   ├── js/circuit.js         # QASM → SVG 电路图（委托 QasmModule）
│   ├── js/builder.js         # 拖拽搭电路（Composer，委托 QasmModule）
│   ├── js/bloch.js           # 布洛赫球（three.js 本地 vendor）
│   ├── js/hgate.js           # H 门游戏（第 1 课）
│   ├── js/socks.js           # 伯特曼袜子游戏
│   └── js/app.js             # 主逻辑（视图/运行/对话/帮助/课程）
├── config/                   # 用户配置（脱敏，git 忽略）
├── run_web.sh                # 启动脚本（DYLD 处理，端口 5011）
└── selfcheck.sh              # ★自检流程 v2（5 项，黑名单从词典 aliases 动态生成）

loomq_lib/                    # pip 可装工具包（Web 的心脏）
├── semantics.py              # 尺子（qelib1.inc）
├── backends.py               # 三后端执行
├── circuits.py               # 22 电路库
├── noise.py                  # L3 噪声模拟（4 机器 + 退极化 + 测量错误 + 拓扑）
└── runner.py                 # run_circuit/verify/validate
```

**关键约定**：
- 内容全部模板化（字典/JSON），更新不动代码
- 颜色一律从 colors.js 取；术语一律从 qc_dict.py 取（禁 hardcode）
- 端口：5011（Web）/ 5010（文档展示）；5001=loomsci、5005=STOP 不可占
- 启动：`bash web/run_web.sh`（DYLD 必须 export 后启动，macOS 26 坑）
- 改 HTML/CSS 后必须重启 Flask（debug=False 不自动 reload）
- 脱敏：config.yaml / config/ / api-key.txt 一律 .gitignore

## 四·五、词典与统一查询（核心设计）

**词典**（`web/qc_dict.py`）：9 字段统一 schema，英文名=唯一键。

| 字段 | 说明 |
|---|---|
| 英文（唯一键） | 规范拼写本身 |
| zh | 中文 |
| aliases | 历史错误变体（自检黑名单来源，仅存纯错误）|
| def_en / def_zh | 一句话解释 |
| detail_en / detail_zh | 详细解释 |
| prereqs | 前置概念（须为词典已有英文键，自动成依赖图）|
| source | 来源（REFERENCES 经典文献 key）|

**统一查询页（帮助 + 词典合并）**：
- 帮助视图顶部**搜索框** → `/api/search`（搜词典词条 + 帮助内容）
- 帮助正文中出现的词典名词（H 门/纠缠/量子比特...）→ **自动链接化** → 点击弹**词典卡片**
- 右下 **LLM 对话集成检索注入**：`/api/chat` 先 `qc_dict.search(message)` → 命中词条注入提示词 → LLM 基于词典回答（防编错定义）

**写作规范**：中文版"中文(英文)"；英文版"仅英文"。审稿聚焦词典一个文件。

## 七、数据流（一条电路的一生）

```
用户（拖拽/选模板/LLM对话）
  → QASM 2.0 文本
  → /api/run
  → loomq_lib.run_circuit(qasm, target, shots)
    ├─ backends.run() → 后端 counts（位序归一化）
    └─ semantics.reference_distribution() → 精确参考分布
  → Hellinger 保真度判定
  → 返回 {counts, reference, fidelity, passed}
  → 前端渲染：电路图 + 双直方图 + 文字结论
```
