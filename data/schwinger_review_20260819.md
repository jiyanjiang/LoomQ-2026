## 二、数学验证（游戏判定核心）

**正交判定表全验证**（矩阵元 ⟨a|b⟩）：
- ⟨↑|↓⟩ = 0 → |↑⟩⟨↑|·|↓⟩⟨↓| = 0 → 挡 ✅
- ⟨↑|+⟩ = 1/√2 ≠ 0 → 透（通过率 1/2）✅
- ⟨↑|−⟩ = 1/√2 ≠ 0 → 透 ✅
- ⟨+|−⟩ = 0 → |+⟩⟨+|·|−⟩⟨−| = 0 → 挡 ✅

**第 7 关 z→x→z（灵魂关）验证**：
- |↑⟩⟨↑| → |+⟩⟨+| → |↓⟩⟨↓|：通过率 = |⟨+|↑⟩|² × |⟨↓|+⟩|² = (1/2)×(1/2) = **1/4 ≠ 0 → 透** ✅
- 物理解读：测 x 后 z 被扰动，|+⟩ 含 ↓ 分量，再筛 ↓ 有 1/4 概率 → 光确实透过 ✅

**第 8 关挑战（挡）存在性**：
- [|↑⟩⟨↑|, |↓⟩⟨↓|]：相邻正交 → 挡 ✅（至少一解）

**结论**：8 关答案唯一确定，判定规则数学无歧义，可胜性成立。

## 四、发现的 2 个可改进点

1. **幂等性讲解缺失**：第 2 关 [|↑⟩⟨↑|,|↑⟩⟨↑|] 玩家可能困惑"两个一样为什么还透"。原理讲解模板需补："同一台筛子筛两次，筛过的还是它自己（|↑⟩⟨↑|²=|↑⟩⟨↑|，幂等）"。
2. **初始光状态未说明**：判定"透"指概率 > 0，不是 100%。建议关卡 UI 用"透（有概率）"而非"透（必然）"，避免误导（原教具也是概率性的）。
